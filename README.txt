MAGIC STEPS WEBSITE — STARTER PROJECT

FILES
- index.html : website content and sections
- style.css  : colours, layout, responsive/mobile styling
- script.js  : mobile menu and automatic copyright year

HOW TO RUN
1. Extract the ZIP folder.
2. Open the folder in VS Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.
4. Edit the files and refresh the browser to see changes.

EDIT THESE BEFORE PUBLISHING
1. TEAM PHOTOS:
   In index.html, search for "randomuser.me".
   Replace each image URL with the real staff photo URL or a local image path.
   Example: create an "images" folder and use src="images/team-member-1.jpg".
   Update each "Team Member" name and role.

2. CENTRE ADDRESSES / MAP:
   The brochure text was used for these draft locations:
   - Shanthapuram: Jamia Safa Mall, Chungam, Pattikkad
   - Akkapparamb: Pandikkad Road, Akkapparamb
   Confirm the exact addresses and map pins with the clinic before publishing.
   The embedded map currently points to the Shanthapuram address.
   You can replace the iframe src with a Google Maps embed URL for the confirmed location.
   The "Get directions" links are Google Maps search links and do not require an API key.

3. CONTACT:
   Phone, email and Instagram links are based on the supplied brochure/profile link.
   Confirm that the phone number is the preferred WhatsApp number.

4. CONTENT:
   The services and school partnership programme are based on the supplied brochure.
   Confirm exact wording, availability and staff credentials with Magic Steps.

NOTE
- Google Fonts, Unsplash and randomuser.me images require an internet connection.
- Google Maps also requires an internet connection.
- The current team portraits are temporary sample images and are not actual clinic staff.
- This is a static HTML/CSS/JS website; no backend or database is required.
